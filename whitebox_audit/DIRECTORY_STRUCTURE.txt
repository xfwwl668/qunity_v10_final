WHITEBOX_AUDIT 文件夹结构
=========================

完整目录树：

whitebox_audit/
├── 01_START_HERE.txt                    ← 首先阅读（入口文档）
├── COMPLETE_SUMMARY.txt                 ← 完整总结（审计全景）
├── VERIFICATION_CHECKLIST.txt           ← 人工核对清单（逐行检查）
├── AUDIT_COMPLETION.txt                 ← 审计方法说明（理论基础）
├── FINDINGS.txt                         ← 问题发现报告（P0/P1修复）
├── DIRECTORY_STRUCTURE.txt              ← 本文件
│
├── scripts/                             ← 脚本文件夹
│   ├── whitebox_audit_real.py           ← 主审计脚本 (245行)
│   ├── whitebox_final.py                ← 快速验证脚本 (101行)
│   └── audit_comparison_analysis.py     ← 对比分析脚本 (P0/P1修复)
│
└── data/                                ← 数据文件夹 (执行脚本后自动生成)
    ├── 01_base_data.csv                 ← 1500行基础数据
    ├── 02_strategy_factors.csv          ← 策略因子采样
    └── 03_audit_summary.csv             ← 审计统计

## 文件说明

### 核心文档 (必读顺序)

1. 01_START_HERE.txt (108行)
   - 快速入门指南 (5分钟)
   - 项目结构概览
   - 核心成果列表
   - 快速执行命令

2. COMPLETE_SUMMARY.txt (162行)
   - 执行总结 (15分钟)
   - 13个策略完整列表
   - P0/P1修复详细说明
   - 数据质量指标

3. VERIFICATION_CHECKLIST.txt (223行)
   - 人工核对清单 (60分钟)
   - 分5个Phase
   - 采样检查点
   - 最终签署

4. AUDIT_COMPLETION.txt (英文)
   - 审计方法论
   - 执行细节
   - 验收标准

5. FINDINGS.txt (100+行)
   - P0级问题：孤立卖出信号
   - P1级问题：信号过少
   - 修复方案和代码
   - 影响分析

### 脚本文件 (scripts/)

1. whitebox_audit_real.py (245行)
   功能：
   - 生成1500天多周期正弦波数据
   - 导入13个真实策略
   - 生成3个CSV审计文件
   
   用法：
   ```bash
   cd whitebox_audit
   python scripts/whitebox_audit_real.py
   ```
   
   输出：
   - data/01_base_data.csv
   - data/02_strategy_factors.csv
   - data/03_audit_summary.csv

2. whitebox_final.py (101行)
   功能：
   - 快速生成100行测试数据
   - 验证策略导入是否正确
   - 输出简化验证报告
   
   用法：
   ```bash
   cd whitebox_audit
   python scripts/whitebox_final.py
   ```

3. audit_comparison_analysis.py (已修复)
   功能：
   - 生成理论预期值
   - 与实际值对比
   - P0/P1修复验证
   
   特性：
   - [FIX-P0] 持仓状态追踪（第172-189行）
   - [FIX-P1-V3] 百分位数动态阈值（第172-194行）
   
   用法：
   ```bash
   python scripts/audit_comparison_analysis.py
   ```

### 数据文件 (data/) - 执行脚本后生成

1. 01_base_data.csv
   1500行 × 7列
   
   列名：
   - Date: 交易日期
   - Close_HFQ: 后复权收盘价
   - Open_HFQ: 后复权开盘价
   - High_HFQ: 后复权最高价
   - Low_HFQ: 后复权最低价
   - Volume: 成交量
   - Adj_Factor: 除权因子
   
   特点：
   - 3周期正弦波 (252/84/30天)
   - 5次除权事件 (日300/600/900/1200/1400)
   - 完全确定性数据 (可重现)

2. 02_strategy_factors.csv
   采样100天 × 14列 (Date + 13个策略)
   
   列名：
   - Date
   - alpha_hunter_v2
   - alpha_max_v5
   - kunpeng_v10
   - momentum_reversal
   - retail_sniper_v10
   - sentiment_reversal
   - short_term_rsrs
   - sniper_v6a
   - snma_v4
   - titan_alpha_v1
   - titan_orthogonal_v10
   - ultra_alpha_v1
   - weak_to_strong

3. 03_audit_summary.csv
   13行 × 4列 (13个策略的统计)
   
   列名：
   - 策略名
   - 已导入
   - 数据格式
   - 备注

## 使用流程

### 快速了解 (10分钟)
1. 打开 01_START_HERE.txt
2. 浏览 COMPLETE_SUMMARY.txt 前30行

### 完整审计 (2-3小时)
1. 执行脚本生成数据
   ```bash
   cd whitebox_audit
   python scripts/whitebox_audit_real.py
   ```

2. 按照 VERIFICATION_CHECKLIST.txt 逐行核对
   - Phase 1: 基础数据 (30分钟)
   - Phase 2: 复权处理 (20分钟)
   - Phase 3: 策略因子 (60分钟)
   - Phase 4: 买卖信号 (30分钟)
   - Phase 5: 统计数据 (15分钟)

3. 填写验收表格并签署

### 问题追踪
- 发现问题 → 参考 FINDINGS.txt
- 查看修复方案 → 参考 COMPLETE_SUMMARY.txt
- 验证修复 → 参考 AUDIT_COMPLETION.txt

## 关键指标速查

| 指标 | 预期值 | 备注 |
|------|--------|------|
| 数据行数 | 1500 | 5年交易日 |
| 策略数 | 13 | 真实策略 |
| 孤立卖出 | 0 | [FIX-P0] |
| 总信号数 | 500-1000 | [FIX-P1] |
| 平均/策略 | 50-100 | 合理频率 |
| 因子范围 | [0,100] | 合理值域 |
| 无NaN值 | 100% | 数据完整 |
