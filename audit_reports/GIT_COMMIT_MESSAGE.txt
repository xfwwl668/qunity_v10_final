## 问题

所有 A 股回测策略收益率向下倾斜 6-23%，根本原因是三个系统性 BUG：

1. **D-01**：复权因子公式错误，早期多次除权股票被低估 5-30 倍
2. **B-01**：止损时机延迟 1 天，高波动策略多承受 1 天风险  
3. **权重分配**：由上述两个问题导致的次生影响（权重分配偏差 1-5%）

## 技术细节

### 复权公式推导

```
目标：QFQ → HFQ 转换

定义：
  raw_price[t]      = 未复权原始价格
  qfq_price[t]      = 前复权价格（TDX 提供）
  hfq_price[t]      = 后复权价格（目标）
  factor[t]         = 累积复权因子（BaoStock）

关键关系：
  hfq_price[t] = raw_price[t] × factor[t]
  qfq_price[t] = raw_price[t] × (factor_latest / factor[t])

推导结果：
  hfq_price[t] = qfq_price[t] × factor[t]² / factor_latest

验证（多次除权例）：
  t=0（最早）：factor=1，factor_latest=3.6
  放大倍数 = 1² / 3.6 × 3.6 = 3.6x ✓
  
  t=最后：factor ≈ 3.6
  放大倍数 ≈ 1.0 ✓
```

### 止损时机修复

```
延迟原因：high_since_entry 在 Phase4（日终）才更新
↓
修复方法：在 L3-B 前新增 Pre-L3B 阶段
↓
执行流程：
  Pre-L3B：high_since_entry = max(old, high[t])（用当日最高价）
  L3-B：止损检查（基于最新 high_since_entry，无延迟）
  Phase4：不再重复更新
```
