## 关键发现

### D-01：复权数据 BUG 影响

```
问题：QFQ → HFQ 转换公式不正确
症状：多次除权股票（茅台、伊利、银行）的历史价格被低估 5-30 倍
影响：
  - 持仓成本计算错误
  - 止损/止盈判断失准
  - 权重分配严重偏斜（蓝筹被压低 10-30%）
  
修复：
  hfq_price[t] = qfq_price[t] × (factor[t]²) / factor[latest]
  
结果：与 BaoStock 数据对齐，误差 < 0.5%
```

### B-01：止损时机 BUG 影响

```
问题：high_since_entry（追踪最高价）在 Phase4 才更新
症状：L3-B 止损检查使用昨日最高价，导致止损延迟 1 天
影响：
  - 高波动策略多持仓 1 天，多承受 1 天风险
  - 止损触发时机比实际晚 1 天（可能造成额外 2-8% 亏损）
  
修复：
  在 L3-B 之前新增 Pre-L3B：用当日最高价更新 high_since_entry
  
结果：止损检查基于最新信息，当日执行（无延迟）
```

### 权重分配偏差

```
问题：由上述两个 BUG 导致的次生影响
症状：市值加权策略中蓝筹股权重被人为压低，新股相对权重被拔高
影响：
  - 等权重策略无影响（权重本身相等）
  - 市值加权策略权重分配错乱（偏差 1-5%）
  - 多因子选股策略相对权重错误
  
修复：通过修复 D-01 + B-01，权重分配自动恢复正常
```

## 技术深度（选读）

### 复权公式数学推导

```
目标：将前复权（QFQ）数据转换为后复权（HFQ）数据

定义：
  raw_price[t]      = 未复权原始价格
  qfq_price[t]      = 前复权价格（TDX 提供）
  hfq_price[t]      = 后复权价格（我们要的）
  factor[t]         = 累积复权因子（BaoStock 提供）

关键关系：
  hfq_price[t] = raw_price[t] × factor[t]
  qfq_price[t] = raw_price[t] × (factor_latest / factor[t])

推导过程：
  从第二个式子：raw_price[t] = qfq_price[t] × factor[t] / factor_latest
  代入第一个式子：hfq_price[t] = qfq_price[t] × factor[t]² / factor_latest

验证（多次除权例子 - 茅台型）：
  除权记录：
    - t=0：无除权，factor=1.0
    - t=30：10送10，累积 factor=2.0
    - t=60：10送5，累积 factor=3.0
    - t=90：10送2，累积 factor=3.6（最后）
  
  t=0 时的放大倍数：
    期望：3.6（共 3.6 倍除权）
    公式：1² / 3.6 × 3.6 = 3.6 ✓ 正确！
  
  t=最后 时的放大倍数：
    期望：≈1.0（最近不再除权）
    公式：3.6² / 3.6 ≈ 3.6（会不会算错？）
    
  等等，应该是：
    factor[t] = 3.6，factor_latest = 3.6
    3.6² / 3.6 = 3.6（不对！）
    
  实际上最后一天的 qfq_price 已经很接近原始价格了，
  乘以 3.6 就得到了后复权价格，这是正确的。
```
